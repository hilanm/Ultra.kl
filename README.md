# ULTRA.KL — Sistema de Gestión

Sistema de gestión y administración comercial desarrollado para **ULTRA.KL**, una tienda de moda urbana y streetwear.

El proyecto busca centralizar y simplificar la administración del negocio mediante una aplicación multiplataforma desarrollada en **Flutter**, con soporte para almacenamiento local y funcionamiento sin conexión a Internet.

## Funcionalidades principales

- **Gestión de productos:** registro de prendas, tallas, colores, imágenes, costos y precios de venta.
- **Gestión de clientes:** información de clientes, perfiles de Instagram e historial de compras.
- **Gestión de pedidos:** creación y seguimiento de pedidos asociados a clientes y productos.
- **Gestión de paquetes:** control de pesos, costos de envío, números de seguimiento y estados logísticos.
- **Control de gastos:** registro y administración de gastos del negocio.
- **Control financiero:** cálculo de ingresos, costos y ganancias.
- **Estadísticas:** seguimiento de ventas, rentabilidad y productos más vendidos.

## Tecnologías

- Flutter
- Dart
- Riverpod
- GoRouter
- Drift (SQLite)
- fl_chart

## Objetivo

Desarrollar una herramienta centralizada que permita optimizar los procesos administrativos y financieros de ULTRA.KL, facilitando el control de las operaciones comerciales y la toma de decisiones.
